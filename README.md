# TRENZON website design

This public workspace contains a standalone web preview and selected styles from the current TRENZON homepage and Categories page.

1. Fork this repository to your GitHub account.
2. Edit the HTML or CSS in your fork. Open index.html locally to preview changes.
3. Open a pull request to TRENZON/trenzon-design, and include before and after screenshots when practical.

Homepage cards are rendered in index.html. If a proposal changes card data, update home-diamond-showcase.json as well.

The team can use accepted design proposals to update the private production website project. Pull requests and merges here do not publish the live site.
